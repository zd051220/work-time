## 验收路径（真实 Edge / 手机浏览器）

1. 打开站点入口 → 确认自动跳转到 `v5.5.html` 正式主页。
2. 正式主页登录 → 底部「游戏」Tab → 「开始游戏」。
3. 工作页：六个岗位可选，选 1 小时开始；等完成后领取，金币与账本只加一次；重复提交同一幂等键不重复发奖。
4. 村庄页（冒险地图「喵喵村庄」或主页「逛商店」）：12 件商品显示价格与词缀；等级不足 / 金币不足的按钮是禁用的。
5. 购买木剑（100 金币）→ 金币减少 100 → 「背包 → 我的装备」出现木剑 → 穿戴后攻击 +2 → 打森林第 1 层回放里伤害升高。
6. 用同一幂等键再提交一次购买 → 金币与装备数量都不变。
7. 全程浏览器控制台 0 报错；测试账号用删号流程清理（函数部署后）或手动删除。

## 已知边界（本次不做）

- 掉落材料（草药/木材/石头等）暂无用途，没有制作/喂食系统。
- 饱食度、心情、亲密度不参与战斗。
- 没有 Boss 层、每日次数限制；装备强化等级未做成 Purchase 门槛（只有商品 `min_level`）。
- 删号 Edge Function 仍未部署，前端删号入口保持「不假装删号」状态。
