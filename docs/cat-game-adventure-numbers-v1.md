## 二、战斗规则（表 `game_combat_rules`）

| 项 | 推荐值 | 意思 |
| --- | --- | --- |
| `crit_chance` | 0.10 | 暴击率基础 10% |
| `luck_crit_bonus` | 0.002 | 每点幸运再加 0.2% 暴击率（幸运 50 → 封顶 95%） |
| `crit_multiplier` | 1.5 | 暴击伤害 ×1.5 |
| `min_damage` | 1 | 攻击减不过防御时，至少打 1 点 |
| `max_turns` | 30 | 30 回合没分出胜负算失败（撤退） |

- 伤害 = max(1, 攻击 − 对方防御)。没有随机浮动，只有暴击是随机的。
- 猫先手。双方属性相同时猫赢。
- 装备加成直接加到攻击、防御、幸运上（目前没有获取装备的途径）。

## 三、升级（表 `game_level_xp`）

升到下一级所需经验 = round(40 × 1.25^(当前等级 − 1))，一共 30 级。每级 **生命上限 +10、攻击 +1、防御 +1**，升级时当前生命也 +10。

| 等级 | 升到下一级需要 |
| --- | --- |
| 1 | 40 |
| 2 | 50 |
| 3 | 63 |
| 5 | 98 |
| 10 | 298 |
| 15 | 909 |
| 20 | 2,776 |
| 25 | 8,470 |
| 30 | 25,849（最高级） |

`game_cats.xp` 的含义定为“当前等级内已获得的经验”，升级时扣掉升级所需的部分。

| 区域 | 层数 | 解锁条件 | 进入至少需要 | 怪物 |

| 新手矿洞 `mine` | 1–15 | 森林到达第 5 层 | 30 生命 | 岩石史莱姆（1–15 层）、洞穴蝙蝠（6–15 层） |

## 七、生命恢复

`hp_regen_per_minute` = **每分钟回 1 点**，从上次状态变化开始算，满血即停。失败只扣血，不掉金币和物品。

## 八、这套数值推算出来是什么节奏

按“只打稳赢的层、输了不算”的策略用公式推算（不含暴击）：

| 节点 | 结果 |
| --- | --- |
| 森林第 10 层 | 约 Lv.3 能稳赢 |
| 矿洞第 15 层 | 约 Lv.9 能稳赢 |
| 遗迹第 20 层 | 约 Lv.19 能稳赢 |
| 三个区域全部打通 | 约 87 场战斗，角色到 Lv.19 |
| 累计掉血 | 约 12,500 点 ≈ **按每分钟 1 点要挂机约 208 小时** |

所以前期很快（前十场就能推完森林、进矿洞），后期主要在等血量恢复。嫌慢最直接的两个调节点：把 `hp_regen_per_minute` 调大，或者把怪物的 `attack_per_floor` 调小。

## 九、怎么改

迁移已经在库里执行过，改数值分两种情况：改迁移文件里的 `insert` 只影响以后新建的库（句尾是 `on conflict do nothing`，重跑不会覆盖已有数据）；要改现在这个库，直接对配置表 `update`，例如 `update public.game_combat_rules set hp_regen_per_minute = 5 where id = 1;`。下表说的是在迁移文件里改哪里：

| 想改什么 | 改哪里 |
| --- | --- |
| 暴击、回合上限、回血速度 | `game_combat_rules` 那一行 |
| 升级快慢、每级加多少 | `game_level_xp` 的 `insert ... select g,round(40*power(1.25,g-1)),10,1,1`（40 是 1 级经验、1.25 是每级倍数、后面三个是每级生命/攻击/防御） |
| 区域层数、解锁条件、进入血量 | `game_zone_catalog` 的三行 |
| 怪物强度、经验、金币 | `game_monster_catalog` 的六行 |
| 掉落 | `game_drop_table` |
