# Stable 正式发布检查清单

每次正式发布复制本清单，并在 PR 或 Release 中记录结果。未执行的项目标记为“未验证”，不得默认勾选。

## 发布信息

- [ ] 目标版本号符合 SemVer。
- [ ] 发布渠道为 Stable。
- [ ] 发布范围、负责人和影响模块已明确。
- [ ] 对应 PR 已审核并合并。
- [ ] Git Tag 指向实际验收的提交。

## 代码与自动化检查

- [ ] 静态审计通过。
- [ ] 计时与工资计算回归通过。
- [ ] 跨午夜、暂停/恢复、异常时间等边界场景已检查。
- [ ] 账本读写与数据隔离检查通过。
- [ ] 游戏相关改动的 RPC/结算测试通过。
- [ ] 数据库 migration 已审计；未涉及则注明“不涉及”。
- [ ] 依赖、资源路径、页面链接和控制台错误已检查。
- [ ] CI 未覆盖的风险项已明确列出。

## 数据与兼容性

- [ ] localStorage/IndexedDB 数据结构兼容性已评估。
- [ ] 云同步/API/RPC 契约兼容性已评估。
- [ ] 数据库 schema 和 migration 历史已核对。
- [ ] 不存在未授权的生产数据变更。
- [ ] 回滚路径与数据风险已评估。

## 用户体验与公告

- [ ] 正式版本号显示正确。
- [ ] 更新检测只比较正式 Stable 渠道。
- [ ] 更新公告内容与 GitHub Release 一致。
- [ ] 更新提示不会强制中断计时或账目录入。
- [ ] 已知问题、兼容性和用户操作说明已发布。

## 部署与线上验证

- [ ] GitHub Release 已创建。
- [ ] Pages 部署工作流成功。
- [ ] 正式网址打开正常。
- [ ] 首页入口与内部导航正确。
- [ ] 关键资源加载正常。
- [ ] 计时、工资、账本核心流程完成线上冒烟测试。
- [ ] 更新检测和缓存行为已验证。
- [ ] 线上验证结果与部署提交 SHA 已记录。
