# Cat companion asset directory

This directory is reserved for the four independent, production-quality cat character assets.

No concept sheet or placeholder artwork is included here. Do not treat the current inline SVG prototypes as final game art.

## Planned asset contract

- Four distinct characters with transparent backgrounds.
- Separate, consistently sized frames or files for idle, work/carry, paid break, unpaid sleep, off-duty celebration, and click interaction.
- Gold bars must be rectangular ingots with visible thickness, beveled edges, and metallic highlights; no coins or ingots shaped like yuanbao.
- Keep source artwork and exported web assets separate; document dimensions, frame order, and licensing before integration.

The PR preview workflow packages this folder as a short-lived GitHub Actions artifact. It does not deploy to GitHub Pages or modify the production site.
