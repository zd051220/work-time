# 小猫搬金条 · work-time

一个纯前端的工作计时 / 搬金记录小工具。所有数据只存在你自己的浏览器里（localStorage），不上传任何服务器。

## 数据怎么存的

- 主页和账本页同域名，共用同一份 localStorage 数据，key 是 `catGold_v5`。
- 所以在主页打的卡，账本页立刻能看到；在账本页删的记录，主页也会消失。
- 首次打开会自动迁移旧版 `catGold_v4 / v3 / v2` 的账本。
- 数据跟着浏览器走：清浏览器数据、换设备、换浏览器都会丢。**重要记录请用「导出备份」存一份 JSON**，换设备后用「导入备份」合并回来。
- 备份导入按记录编号合并，不会重复；备份里的“进行中打卡”不会被重新接上继续计时。

## 修改和上线

仓库是 GitHub Pages，`main` 分支根目录即站点。改完提交到 `main`，等 1 分钟左右自动生效。

- 改页面：直接编辑对应的 `.html` 文件
- 新增页面：放根目录，用相对路径互相链接即可
- 浏览器缓存：如果改了没生效，在地址后面加 `?v=2` 这类参数强刷一次
