## 计时与账本规则

- 实际工作、带薪摸鱼计入计薪时长；不带薪摸鱼暂停计薪。
- 跨午夜计时按自然日拆分记录。
- **无感信任：** 计时以系统当前时间为准，不运行双时钟偏差检测，也不做服务器时间反作弊校验。
- **切回直接补时：** 页面切到后台、浏览器切换或手机锁屏期间，恢复页面后直接按时间戳差值补计工时；不弹窗、不报警、不冻结，也不要求人工核对。
- **账本可修改：** 如果忘记下班或结束时间记录不准确，可以在账本中修改该条记录的结束时间，系统会重新计算工时与工资。
- 本地与云端数据按用户身份隔离。

## 开发与发布约定

- 在独立分支完成改动，通过审查和自动化测试后再合并到 `main`。
- 自动化测试通过不等于真实设备和生产环境端到端测试通过；设备实测范围应如实记录。
- 不擅自修改生产数据库；数据库迁移必须先核对生产 schema 与迁移历史。
- 不得将 Supabase service_role 或其他服务端秘密放入前端或仓库。
- 正式入口保持稳定，清理历史版本前先确认没有仍在使用的引用。
